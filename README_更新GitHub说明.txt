AI智营宝 V1.1 GitHub Pages 更新说明

当前仓库：https://github.com/phycocy2026/AIYingBao
网站：https://phycocy2026.github.io/AIYingBao/

更新方法：
1. 解压本压缩包。
2. 打开 GitHub 仓库 AIYingBao。
3. 点击 Add file → Upload files。
4. 上传本包中的 index.html、manifest.webmanifest、sw.js、icons 文件夹和 .nojekyll。
5. 如果 GitHub 提示同名文件，直接提交（Commit changes），新版本会覆盖旧版本。
6. GitHub Pages 不需要重新设置，仍然使用 main / (root)。
7. 等待约 1–5 分钟后刷新网页。
8. iPhone 若仍显示旧页面，可完全关闭 Safari 后重开；PWA 已更换缓存版本为 v1.1。
