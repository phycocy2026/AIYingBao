AI智营宝 手机PWA版 使用说明

推荐方式：部署到 HTTPS 网站后用手机浏览器访问。

Android：
1. 用 Chrome/Edge 打开网址。
2. 点击“拍照 / 选择餐食照片”，可直接调用后置摄像头或相册。
3. 浏览器出现“安装应用”提示时可安装；也可菜单 -> 添加到主屏幕。

iPhone：
1. 用 Safari 打开网址。
2. 点击“拍照 / 选择餐食照片”，选择“拍照”或“照片图库”。
3. Safari 分享按钮 -> 添加到主屏幕。

注意：
- PWA 安装和摄像头能力在 HTTPS 环境最稳定。
- 当前 AI 模型通过 CDN 加载，首次识别需要联网。
- 若仅把 index.html 作为本地文件打开，PWA 安装/service worker 不会生效。
